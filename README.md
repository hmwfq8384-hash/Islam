# بطاقتي الإيمانية – Islamic Card Designer

تطبيق ويب عربي لإنشاء بطاقات دينية قابلة للتخصيص. يعمل كتطبيق Static ويمكن نشره مباشرة على **Cloudflare Pages**.

## التشغيل محلياً
افتح `index.html` في متصفح حديث. للحصول على أفضل نتيجة استخدم خادماً محلياً بسيطاً أو Cloudflare Pages.

## النشر على Cloudflare Pages
1. فك ضغط الملف.
2. ارفع المجلد إلى مستودع GitHub.
3. من Cloudflare اختر **Workers & Pages → Create → Pages → Connect to Git**.
4. اختر المستودع.
5. اترك Framework preset على `None`.
6. اجعل Build command فارغاً.
7. اجعل Build output directory هو `/` أو `.` حسب واجهة Cloudflare.
8. اضغط Deploy.

لا يحتاج التطبيق إلى Worker أو قاعدة بيانات أو مفاتيح API. التصميمات تحفظ في `localStorage` على نفس المتصفح والجهاز.

## المزايا
- إدخال النص الأساسي والآية والحديث والاقتباس كلٌ في حقل مستقل.
- مصدر الآية وتخريج الحديث والراوي.
- ستة قوالب لونية.
- ثلاثة مقاسات للنشر.
- رفع صورة كخلفية أو أعلى/أسفل البطاقة.
- تحكم بالشفافية والألوان والخط وحجم النص.
- ترتيب أقسام البطاقة بالسحب والإفلات.
- معاينة مباشرة.
- حفظ وفتح وحذف التصميمات محلياً.
- تصدير PNG.

## ملاحظات مهمة
- خطوط Google Fonts ومكتبة html2canvas تُحمّل من الإنترنت؛ التصدير يحتاج اتصالاً بالإنترنت عند أول استخدام.
- البيانات محفوظة محلياً في المتصفح، وليست متزامنة بين الأجهزة.
- لا يقوم التطبيق بتوثيق النصوص الدينية آلياً. تحقق من الآيات والأحاديث ومصادرها قبل النشر.
- لا توجد خدمة حسابات أو تخزين سحابي في هذه النسخة؛ لا يلزم أي إعدادات أسرار أو مفاتيح.

## الملفات
- `index.html` الواجهة.
- `styles.css` التصميم والتجاوب.
- `app.js` منطق التطبيق.
- `_headers` ترويسات أمان أساسية لـ Cloudflare Pages.
